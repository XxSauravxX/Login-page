# PHP & MySQL Login System

A simple login system developed using PHP, MySQL, JavaScript, HTML, and CSS.

## Features

- User login authentication
- MySQL database integration
- Password verification
- JavaScript form validation
- Session-based authentication
- User profile page
- Logout functionality
- Responsive and clean user interface

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Project Structure

```text
login-page/
├── index.php
├── profile.php
├── db.php
├── logout.php
├── style.css
└── script.js

How to Run Locally
Install XAMPP.
Start Apache and MySQL.
Place the project folder inside the htdocs directory.
Create the required MySQL database and users table.
Update the database credentials in db.php.
Open the project through localhost.
